# 🏥 Медицинский подход "После любви"

## Обзор

Бот реализует полный цикл психотерапевтического сопровождения после расставания, основанный на медицинской модели:

### 🔄 Полный цикл лечения

```
Первичный приём (анамнез)
    ↓
Диагностика (определение состояния)
    ↓
Постановка диагноза (тяжесть + тип терапии)
    ↓
План лечения (цели на 3-6 месяцев)
    ↓
Назначения (техники, дневник, задания)
    ↓
Мониторинг (еженедельно + переоценка)
    ↓
Фоллоу-апы (1, 3, 6 месяцев)
    ↓
Завершение (итоговая оценка + профилактика)
```

---

## 📋 Фазы реализации

### Фаза 1: Первичный приём (Intake)
**Файлы:** `handlers/intake.py`, `db.save_intake()`, `db.get_intake()`

**Что происходит:**
- `/start` перенаправляет на сбор анамнеза
- 5 вопросов о ситуации:
  - Сколько времени прошло после расставания
  - Кто был инициатором
  - Длительность отношений
  - Были ли дети/имущество
  - История прошлых расставаний

**Результат:** Сохранённый анамнез в БД для контекста

---

### Фаза 2: Расширенная диагностика
**Файлы:** `diagnosis.py`, `handlers/start.py`, `db.save_diagnosis_report()`

**Что происходит:**
- 7-балльная диагностика (4 состояния)
- Определение **степени тяжести**:
  - 🔴 Тяжёлая (кризис)
  - 🟡 Средняя (стабилизация)
  - 🟢 Лёгкая (восстановление/здоров)
- Определение **рекомендуемых методов терапии**:
  - КПТ, схема-терапия, ДПДГ, экзистенциальная, коучинг

**Результат:** Полный диагностический отчёт с рекомендациями

---

### Фаза 3: План лечения
**Файлы:** `treatment_plan.py`, `db.save_treatment_plan()`, `db.get_treatment_plan()`

**Что происходит:**
- Генерируется индивидуальный план с:
  - **Краткосрочные цели** (2-4 недели)
  - **Среднесрочные цели** (1-3 месяца)
  - **Долгосрочные цели** (3-6 месяцев)
- Каждая цель содержит конкретные задачи (objectives)
- Указаны рекомендуемые интервенции

**Команда:** `/план` — показывает полный план

**Результат:** Структурированный путь лечения

---

### Фаза 4: Мониторинг прогресса
**Файлы:** `progress_monitoring.py`, `handlers/menu.py` (команда `/прогресс`)

**Что происходит:**
- Анализ прогресса между диагностиками
- Определение тренда:
  - 🌱 **Прогресс** — улучшение на 10+ баллов или переход в лучшее состояние
  - ➡️ **Стабильно** — минимальные изменения
  - ⚠️ **Регресс** — ухудшение на 10+ баллов или переход в худшее состояние
- Анализ улучшений в тестах (BDI, BAI, GAD-7, и т.д.)

**Команда:** `/прогресс` — выводит отчёт о тренде

**Результат:** Объективная оценка прогресса или регресса

---

### Фаза 5: Фоллоу-апы
**Файлы:** `followup.py`, `scheduler.py` (проверка в 9:00 UTC)

**Что происходит:**
- Планируются проверки на **1, 3, 6 месяцев** после первой диагностики
- Автоматические напоминания (если время пришло)
- Проверка статуса в меню (`/my_state`)

**Примеры сообщений:**
```
🔔 Проверка через 1 месяц
Привет! Как дела? Как ты справляешься с расставанием?
Давай пройдём обновлённую диагностику.
```

**Результат:** Системный мониторинг восстановления на длительный период

## 🗄️ Структура БД

### Новые таблицы

```sql
-- Анамнез
CREATE TABLE user_intake (
    user_id INTEGER UNIQUE,
    breakup_date TEXT,
    initiator TEXT,
    relationship_duration TEXT,
    children TEXT,
    previous_breakups TEXT,
    timestamp TEXT
);

-- Полные диагнозы
CREATE TABLE diagnoses (
    user_id INTEGER,
    state TEXT,
    score INTEGER,
    severity_level TEXT,      -- тяжёлая/средняя/лёгкая
    severity_code TEXT,       -- severe/moderate/mild
    severity_description TEXT,
    therapies TEXT,           -- JSON список методов
    intake_context TEXT,
    timestamp TEXT
);

-- Планы лечения
CREATE TABLE treatment_plans (
    user_id INTEGER UNIQUE,
    state TEXT,
    severity_level TEXT,
    short_term_goals TEXT,    -- JSON
    mid_term_goals TEXT,      -- JSON
    long_term_goals TEXT,     -- JSON
    start_date TEXT,
    expected_end_date TEXT,
    status TEXT DEFAULT 'active',
    timestamp TEXT
);
```

## 💡 Примеры диагностического отчёта

### Кризис (тяжёлая)

```
🔍 ДИАГНОСТИЧЕСКИЙ ОТЧЁТ

Состояние: кризис
Баллы: 18
Степень тяжести: тяжёлая

Вы находитесь в кризисном состоянии. Испытываются острые признаки 
дистресса: суицидальные мысли, паническая атака, полная дезориентация...

Рекомендуемые методы работы:
1. Кризисная интервенция — Техники заземления, стабилизация, безопасность
2. Медикаментозная поддержка — Консультация психиатра при необходимости
3. ДПДГ — Для обработки травматического опыта

📋 ПЛАН ЛЕЧЕНИЯ

Краткосрочные цели (2-4 недели):
• Снизить острую симптоматику
  ✓ Освоить технику дыхания 4-7-8
  ✓ Практиковать заземление 5 чувств
  ✓ Установить режим сна

• Обеспечить безопасность
  ✓ Определить план действий при суицидальных мыслях
  ✓ Иметь под рукой номера кризисных линий
```

### Стабилизация (средняя)

```
🔍 ДИАГНОСТИЧЕСКИЙ ОТЧЁТ

Состояние: стабилизация
Баллы: 10
Степень тяжести: средняя

Ты начал(а) справляться с острой болью, но состояние нестабильно...

Рекомендуемые методы работы:
1. Схема-терапия — Работа с дезадаптивными режимами
2. Когнитивно-поведенческая терапия (КПТ) — Изменение мышления и поведения
3. Диалектическая поведенческая терапия (ДПТ) — Принятие + изменение

📋 ПЛАН ЛЕЧЕНИЯ

Краткосрочные цели (1-2 недели):
• Стабилизировать режим
  ✓ Установить регулярный режим сна
  ✓ Питаться в одно время
  ✓ Ежедневная прогулка 30 минут
```

## 🔔 Фоллоу-ап система

**Автоматические проверки:**

1. **1 месяц** — Первая оценка стабильности
2. **3 месяца** — Глубокая переоценка (критический период)
3. **6 месяцев** — Финальная оценка перед завершением

**Автоматические напоминания:** Отправляются в 9:00 UTC если время пришло

```
🔔 Проверка через 1 месяц

Привет! Как дела? Как ты справляешься с расставанием?
Давай пройдём обновлённую диагностику, чтобы оценить прогресс.
Нажми /start, чтобы начать.
```

## 📈 Полный цикл пациента

```
День 1:
  - /start → первичный приём (анамнез) → диагностика
  - Результат: Диагноз + План лечения + Рекомендации
  - Начало: Дневник, техники, дневные задания

День 2-30:
  - Ежедневные техники (утро/вечер)
  - Дневник + AI-анализ
  - Дневные задания
  - OARS-разборы при необходимости

День 30: ⏰ ФОЛЛОУ-АП 1
  - Автоматическое напоминание
  - Повторная диагностика
  - Анализ прогресса/регресса
  - Корректировка плана если нужно

День 31-90:
  - Продолжение программы
  - Переход на среднесрочные цели

День 90: ⏰ ФОЛЛОУ-АП 2 (КРИТИЧЕСКИЙ)
  - Переоценка
  - Смена методов если регресс
  - Углубленная работа

День 91-180:
  - Долгосрочные цели
  - Подготовка к завершению

День 180: ⏰ ФОЛЛОУ-АП 3 (ФИНАЛЬНЫЙ)
  - Итоговая оценка
  - План профилактики
  - Переход на поддерживающий режим
```
